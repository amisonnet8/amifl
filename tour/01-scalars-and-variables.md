## スカラー型(`amifl-spec.md` §2.1)

AmiFLの基本型は次の通りです。

| 種類 | 型 | 備考 |
|---|---|---|
| 符号付き整数 | `Int8` `Int16` `Int32` `Int64` | `Int`は`Int64`のエイリアス(既定の整数型) |
| 符号なし整数 | `UInt8` `UInt16` `UInt32` `UInt64` | `UInt`は`UInt64`のエイリアス。`Byte`は`UInt8`のエイリアス |
| 浮動小数点 | `Float32` `Float64` | `Float`は`Float64`のエイリアス(既定) |
| 真偽値 | `Bool` | |
| 文字列 | `String` | UTF-8、イミュータブル |

**サイズや符号の異なる数値型どうしは、一切暗黙変換しません**(原則2)。`Int32`の値をそのまま`Int64`の変数へ代入することもできません——`Int32`と`Int64`は完全に別の型として扱われます。明示的に変換したい場合は`cast[T](v)`を使います(6章で扱います)。`Int`と`Int64`のようなエイリアス対は、同じ型として扱われます。

## `let`と`const`(§4)

```amifl
const Pi: Float = 3.14159265
let count: Int = 0
```

- **`let`**は実行時変数です。再代入でき、初期化式には任意の式を書けます。ただし**トップレベルでの`let`宣言は禁止**されています(原則5、グローバル可変状態の排除)——`let`は必ず`fn`の本体やブロックの中に書きます。
- **`const`**はコンパイル時にのみ存在する値で、実行時のストレージを一切持ちません。初期化式は「リテラル・他の`const`参照・それらの演算」に限られますが、トップレベルに書けます。再代入はできません。

```amifl
fn main() -> Int {
    let x = 10       // 再代入できる
    x = 20            // 再代入(letのみ可能。関数引数・for束縛変数は不可)
    let y: Int8 = 5   // 型注釈は省略できる場合が多い

    x
}
```

同じ関数・クロージャー内で、内側のブロックが外側と同じ名前の`let`を再宣言すること(シャドーイング)もできます——`x`が「今どちらを指しているか」は、常にその時点で一番内側の宣言になります。

AmiFLはブロック(`{ }`)の中の改行を「式の区切り」として扱います(§5)。**この区切りが働くのはブロック直下だけ**なので、`if`条件式のような、閉じトークンを持たない式の途中で改行を挟むことはできません。一方、`[...]`(リスト/配列)・`(...)`(タプル・呼び出し引数)・`{...}`(struct/Set/Mapリテラル)のように自分自身の閉じトークンで区切られる箇所は、要素ごとに改行を挟んで複数行に書けます(末尾カンマも可):

```amifl
let xs: List[Int] = [
    1,
    2,
    3,
]
```

それでも、二項演算子の左右のように閉じトークンを持たない位置の途中で改行するのは変わらず構文エラーです。長い式を書くときは、`let`で途中結果に名前を付けて分割するのが基本です。

## リテラルは「無型」(§2.1)

整数・浮動小数点リテラルは、それ自体は型を持たず、使われる文脈に応じて型が決まります。

```amifl
let a: Int8 = 5      // 5はInt8として解決される
let b: UInt64 = 5    // 同じ5がUInt64として解決される
let c = 5             // 期待型が無ければInt64が既定
```

浮動小数点リテラルが整数系の型へ適応することは決してありません(小数点情報を静かに落とさないため)。

```amifl
let n: Int = 3.14   // コンパイルエラー——Floatのリテラルは整数型に適応しない
```

## 数値リテラルの書き方(§3.1)

10進数のほか、16進(`0x`)・8進(`0o`)・2進(`0b`)のプレフィックス付きリテラルが書けます。桁区切りの`_`も、基数プレフィックスの直後や数字と数字の間に自由に置けます。

```amifl
let hexMask: Int = 0xFF        // 255
let octPerm: Int = 0o17        // 15
let binFlags: Int = 0b1010     // 10
let big: Int = 1_000_000        // 1000000(桁区切り)
```

先頭ゼロ付きの10進表記(`017`のような)はコンパイルエラーになります——`0`から始まる複数桁の並びは基数プレフィックスと解釈されるべきだからです(`0o17`と書き直すか、単に先頭の`0`を落としてください)。

## 演算子(§6)

```amifl
fn main() -> Int {
    let a = 7 + 3 * 2      // 13(掛け算が先)
    let b = (7 + 3) * 2    // 20
    let c = -5              // 単項マイナス
    let s = "foo" + "bar"  // "foobar"(+はStringのConcatenable)

    a
}
```

算術演算子(`+ - * / %`)は左右の型が完全一致していなければなりません——`Int8`と`Int64`を足すことはできず、片方を明示的に`cast`する必要があります。**`+`は`String`専用のConcatenableで、`List`/`Array`の連結には使えません**(それらは13.4節の`concat()`という組み込み関数を使います、6章で扱います)。

比較演算子(`== != < <= > >=`)・論理演算子(`&& || !`)・ビット演算子(`& | ^ &^ ~`)・シフト演算子(`<< >>`)もあります。**`&&`/`||`は短絡評価ではありません**——両オペランドを無条件に評価してから論理演算を適用するため、右辺の評価が安全でない場面(境界外アクセスのリスクがある式など)は、ネストした`if`で書き直す必要があります(§6)。

優先順位は`() . [] 呼び出し 後置?` → 単項`! - ~` → `* / % << >> & &^` → `+ - | ^` → `< <= > >=` → `== !=` → `&&` → `||` → `.. ..=` → `|>`(最低)の順です。`..`/`..=`(範囲)と`|>`(パイプ)は4章・6章で扱います。

## `_ = expr`——値を捨てる(§5)

AmiFLは式指向言語で、ブロックの中で最後以外の式は必ず`Unit`型(値の無い型)でなければなりません。値を持つ式の結果をあえて使わない場合は、`_ = expr`と明示します。

```amifl
fn main() -> Int {
    let x = 5
    _ = x + 1   // x+1の値をここでは使わない、と明示する
    0
}
```

これはGoコンパイラの未使用変数対策ではなく、純粋にAmiFL自身の型規律のための構文です——「ブロックの途中に値を捨てる式を置いてよいのは、明示的にそう書いた場合だけ」というルールを、コンパイラが機械的に強制しています。

## 演習

1. `Int16`型の変数`a`に`1000`、`Int16`型の変数`b`に`2000`を束縛し、`a + b`を`print`するプログラムを書いてください(`main`の戻り値は`0`のままでかまいません)。
2. `const`を使って、直径`10.0`の円の円周(`直径 * 3.14159`)を計算し`print`するプログラムを書いてください。`Pi`という名前の`const`を定義し、直径と円周率の掛け算に使ってみましょう。

<details>
<summary>解答例</summary>

```amifl
fn main() -> Int {
    let a: Int16 = 1000
    let b: Int16 = 2000
    let sum = a + b
    print(sum)
    0
}
```

```amifl
const Pi: Float = 3.14159

fn main() -> Int {
    let diameter: Float = 10.0
    let circumference = diameter * Pi
    print(circumference)
    0
}
```

`const`の初期化式はリテラルや他の`const`参照の演算に限られますが、`diameter * Pi`のような**実行時の**掛け算は`let`側で普通に書けます——`const`はコンパイル時定数、`let`は実行時変数、という役割分担です。

</details>
